# Quoridor — Дизайн-токены (аудит для редизайна)

Дата аудита: 2026-10-15. Источник: только исходный код CSS/HTML (без запуска).
Computed-стили через Playwright **не снимались** — см. §6.

Файлы стилей:
- `frontend/css/style.css` (4248 строк) — основное приложение (SPA).
- `frontend/css/auth.css` (146) — формы входа/регистрации.
- `frontend/css/auth-pages.css` (396) — общие стили статических страниц (rules/faq/terms/privacy/report…).
- `frontend/css/profile.css` (760) — страница профиля.
- `frontend/css/replay.css` (498) — страница реплея.
- Admin-страницы (`admin*.html`) — **инлайн `<style>` в каждом файле**, собственный `:root`.

### 1.2 Светлая тема — `style.css` `body.light` (строки 367–381)

```css
body.light { --bg:#f0f0f0; --bg-2:#f7f7f7; --board:#ddd; --text:#222; --wall:#d35400 }
body.light #panel { background:#fff }
body.light canvas { background:#ddd }
```

> **Важно**: тема переключается через `document.body.className = theme`, но в разметке `#themeSelect`/`#themeSelectInline` присутствует **только опция `value="dark"`**. То есть светлая тема объявлена в CSS, но выбрать её в UI нельзя. `data-theme` на `documentElement` нигде не выставляется (только читается в `ui.js:3021`). Фактически приложение — тёмное, тема «заглушка».

## 4. Отступы и раскладка (выборочно)

- Хедер: `padding: 0 5%`, `height: var(--header-h)` (64px).
- Частые `gap`: `8px`, `10px`, `12px`, `16px`, `20px`.
- Частые `padding`: `8px`, `10px`, `12px`, `16px`, `20px`, `24px`.
- Раскладка в основном через `flex` и `grid` (`grid-template-columns: repeat(auto-fit, minmax(...))` в admin/profile).
- `backdrop-filter: blur(12px)` на шапке; `user-select: none` на body (ощущение «нативного» приложения).
- Скроллбары стилизуются кастомно (см. `style.css`).

> Полной spacing-шкалы (токенов `--space-*`) нет.

## 6. Computed styles (Playwright) — **НЕ СОБРАНО**

По решению заказчика аудит выполняется **только по коду, без запуска приложения**, поэтому вычисленные через `getComputedStyle` значения для шапки, кнопок (primary/secondary/ghost), карточек, таблиц, чипов, переключателей, модалок, плашек игроков, ряда стен и списка ходов **не снимались**.

Чтобы дособрать (когда будет разрешён запуск):
1. Поднять локально `docker compose -f docker-compose.dev.yml up -d --build` (даст чистую БД/данные).
2. Открыть в Playwright `http://localhost:3000` (1440×900), включить класс состояния (`body`, `.screen.active` для `gameScreen`/`profileScreen`) и снять `getComputedStyle` по селекторам: `.main-header`, `.primary-btn`, `.secondary-btn`, `.h-btn`, `.info-card`, `.pp-stat-card`, таблицы (`.pp-history-table`, `admin .panel`), `.eval-switch`, `.modal-content`, `.player-bar`, `.wall-inventory`, `#historyList`, `.presence-list`.
3. Значения записать сюда в виде таблиц (selector → property → value) и указать цепочку источников (переменная → значение).

Ориентировочный список селекторов для съёма — см. `components.md` (там перечислены компоненты).
