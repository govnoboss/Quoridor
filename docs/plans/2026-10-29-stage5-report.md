Дата: 2026-10-29. Ветка: `redesign/full`.
Основание: баг-список пользователя по скриншотам живого сайта + канон полного
десктопного игрового экрана `design-reference/html/canvas1-Main.html`

## 3. Расхождения и решения

1. **Канон двух макетов** (`GamePanel.html` vs `canvas1-Main.html`) — выбран
   `canvas1-Main`: rail 28px без pawn-dot, сайдбар 300px, nav-кнопки
   `#222327`/`#b5b8be`; `GamePanel.html` остаётся эталоном eval-карточки
   (совпадала без изменений). Игрок подтвердил выбор.
2. **`--wall` → `#e8a02f`**: макет рисует стены `#e8a02f`, токен был
   `#f0a82a` (совпадает с `--accent`). Изменён сам токен `--wall` (семантика —
   цвет стены) + канвасная стена переключена с `--accent` на `--wall`;
   `--accent`/eval-midline не тронуты (системный акцент — токен).
3. **Полоса хода**: макет подчёркивает активную плашку `#e8a02f`; заменён
   литерал (аналогично решению этапа 4 для Confirm/Restart).
4. **Геометрия стен**: прежняя формула `fullLen - gap*2` сохранена; изменилась
   семантика трима (`gap` 8 → 2.4 = половина зазора 3/75·120) — размещение
   (слоты, hit-тесты) не затронуто, только отрисовка.
5. **`.history-container-wrapper`**: базовое правило осталось для hidden
   drag-шаблонов (они `display:none` — проверено), переопределение только в
   bot-режиме; online-сайдбар не пострадал.
6. **Футер**: на скриншоте пользователя — старая задеплоенная версия;
   в SPA-разметке футера нет и в игре его не будет (site-shell монтируется
   только на статических страницах).
7. **Replay-страница**: `replay.html` использует те же `.player-bar`/`.avatar`
   — визуально она тоже переехала на новый стиль (согласуется с макетами той
   же линейки).
8. **evalSwitch в автотесте дважды кликался**: не баг, артефакт теста
   (перегрузка страницы при прогоне).
