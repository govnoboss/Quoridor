# Отчёт · ТЗ 2a — Главная: масштабирование под любой экран

Дата: 2026-10-30. Ветка: `redesign/full`.
Основание: `tz-02a-home-scaling.md` (правка к этапу 2).

## 1. Что сделано

### Решение — единый масштаб `--s`

- **`frontend/index.html`**: в `<head>` добавлен компактный inline-скрипт с формулой
  ТЗ: `s = clamp(0.7, min(W/1440, (H−112)/664), 2.0)`, `W < 1320 → s = 1` (одноколоночный
  макет без zoom). Считается синхронно до отрисовки (без вспышки), пересчёт на
  `resize`/`orientationchange` c rAF-троттлингом; глобальный хук `window.__updateHomeScale`
  используется при возврате на главную. Три колонки обёрнуты в контейнер `.home`
  (внутри `.home-layout`); `#dynamicPanel`, `#searchOverlay`, модалки и хедер лежат
  **вне** `.home` и не масштабируются (проверено вычислением цепочки `zoom`).
- **`frontend/css/style.css`**:
  - `.home { display:flex; gap:48px; zoom: var(--s,1); }` + guard
    `@supports not (zoom:1)` для старых браузеров; внутренние размеры не менялись;
  - `.home-layout`: `flex: 1 1 auto → 0 0 auto` — контейнер больше не растягивается
    на зону подвала;
  - `#mainMenu`: добавлен `padding-bottom: 56px` — центрирование композиции идёт
    строго между шапкой (56) и подвалом (56), воздух сверху/снизу равный (было
    130 px сверху / 74 px до подвала на 1440×900);
  - `@media (max-width:1319px)`: `.home { display: contents; }` — на узких экранах
    колонки снова прямые дети `.home-layout`, zoom выключен.
- **`frontend/js/game.js`** (`DemoBoard`): буфер демо-доски теперь
  `528 × dpr × s` (dpr зажат 2…3, s ≤ 2), пересчёт по событию `home-scale-change`
  и при `init()`; при `s = 1` буфер остаётся 1056 как раньше. `applyDemoTheme()`
  пересчитывает `k` под новый буфер, изображение не мылится при `s > 1`.
- **`frontend/js/ui.js`** (`showScreen`): при `id === 'mainMenu'` вызывается
  `window.__updateHomeScale()` — возврат с игрового экрана пересчитывает `--s`
  (пока был в игре, окно могли ресайзить).
- Bump: `style.css 1.0.30 → 1.0.31` (везде, где подключался), `ui.js 1.0.27 → 1.0.28`,
  `game.js 1.0.18 → 1.0.19`.
